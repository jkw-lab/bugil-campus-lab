# BUGIL CAMPUS LAB

천안 북일고등학교 캠퍼스를 **공개된 사진을 기준으로 개략 재구성한 독립 제작 3D 브라우저 시제품**입니다. 학교 공식 게임이 아니며 위치·건물 크기는 실측치가 아닙니다.

## v0.2 — 캠퍼스 외관 개선

- 공식 캠퍼스 안내 화면과 제공된 위성사진을 기준으로 대운동장 북쪽 본관, 동쪽 아단관, 남쪽 현암관, 서쪽 야구장, 동남쪽 기숙사 신관 등의 상대 위치 재배치
- campus-data.js에 건물 이름, 번호, 3D 기준 좌표, 다중 건물 매스, 배치 신뢰도 정리
- 본관 중앙 박공부·계단·태양광 패널·조경, 아단관 다중 외벽, 체육관과 기숙사 등 고유 외관
- 운동장, 야구장, 코트, 도로, 주차장 및 북쪽 숲·경사지 표현
- 모바일·태블릿 대응 건물 선택, 시점 전환, 명칭 표시, 창문 강조
- 기존 한 번에 건물이 사라지던 효과 대신 실험적인 3D 블록 분리/복구 기능

## 개발 구조

- index.html: 게임 시작 화면과 메뉴
- styles.css: 반응형 UI
- campus-data.js: 시설별 독립 좌표/다중 매스 정보
- main.js: Three.js 3D 장면, 오브젝트 생성, 카메라 및 상호작용

정밀한 학교 도면이나 실내 접근 정보는 포함하지 않았습니다. 내부 시설과 출입 경로를 재현하는 목적이 아닌, 외관을 표현한 비공식 아트/게임 시제품입니다.

## 실행

공개 사이트: https://bugil-campus-live.vercel.app

GitHub main 브랜치 변경 사항은 연결된 Vercel 프로젝트에서 자동 배포됩니다.
PC 테스트: 저장소에서 python -m http.server 8000 실행 후 http://localhost:8000 접속

Three.js와 OrbitControls를 CDN에서 가져오기 때문에 인터넷 연결이 필요합니다. Three.js의 MIT 라이선스를 준수합니다.

## 자료와 한계

- 북일고 공식 캠퍼스 가이드: https://www.bugil.hs.kr/about/campus.php
- 사용자가 제공한 공중사진과 Apple 지도 위성화면
- 건물 배치, 방향, 지형, 높이, 창문은 사진에 기반한 시각적 추정입니다. 측량·검증된 좌표가 아니며 모양이 실물과 다를 수 있습니다.
- 기존 SMASH 대학교 게임의 코드·에셋을 복제하지 않고 직접 생성한 3D 모형입니다.
