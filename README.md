# BUGIL CAMPUS LAB · v0.4

북일고의 **야외 건물 배치와 지형**을 사진을 참고해 재구성하는 비공식 3D 시제품입니다. 기존 SMASH 게임의 코드와 에셋을 사용하지 않았습니다.

## v0.4 — 건물 배치와 지면 높이 정리

- 사용자가 제공한 항공사진의 건물 표기와 도로 하이라이트를 기준으로 본관, 아단관, 현암관, 창의관, 써미트홀, 여송학사 본관·신관 위치를 재보정
- 동일한 `terrain-model.js`의 높이 계산을 지면·건물 바닥·도로·운동장·야구장·주차장·나무에 적용
- 운동장 2곳, 야구장, 건물별 부지에 평탄한 영역을 두고 사면으로 부드럽게 연결
- 북쪽 산지와 남쪽/서쪽 완만한 높이 차를 **게임 안에서 시각적으로 추정**하여 표현
- 도로 곡선이 달라진 건물과 겹치지 않도록 동측·남측 일부 도로 수정
- 태블릿 하단의 **고도 보기** 버튼으로 색상으로 표현되는 상대 높낮이 확인 가능
- 건물 탐색 정보에 건물별 게임 기준 상대 높이 표시
- 기존 건물 블록 분리·복구·카메라 회전 기능 유지

## 프로젝트 파일

- `index.html` / `styles.css`: 화면과 iPad 조작 메뉴
- `campus-data.js`: 교사동·기숙사·운동장 위치와 개략 외곽
- `roads-data.js`: 도로와 보행로의 경로, 부지 외곽
- `terrain-model.js`: 통일된 높이 함수와 건물별 평탄부, 색상 구간
- `main.js`: Three.js 지형, 건물, 도로, 파괴 효과와 상호작용

## 실행

https://bugil-campus-live.vercel.app

## 출처·제약

- 북일고 공식 캠퍼스 안내: https://www.bugil.hs.kr/about/campus.php
- 제공된 지도 스크린샷과 건물별 JPG 41장 레퍼런스
- 상대 고도는 **실제 측량값, DEM 지형 모델, GPS 정보가 아니라 시각적 추정치**입니다. 지도와 치수도 실제 이동 경로나 출입 안내에 사용할 수 없습니다.
- 학교 사진은 레퍼런스로만 활용했으며 제3자 저작권 보호를 위해 원본 사진 파일은 게임 리포지토리에 포함하지 않습니다.
- Three.js MIT 라이선스 적용.


## v0.4.1 DEM 미리보기 실험 (검증 전)

사용자 제공 `bugil_terrain(1).zip`의 2025년 수치지형도 DXF 기반 등고선·표고점 보간고도를 사용한다. 모바일 시각화를 위해 원본 5m 격자를 25m 간격으로 샘플링하고 0.5m로 양자화한 `height-grid.js`를 사용한다. 고도 원본에는 201x241개의 5m 보간 격자가 포함되어 있다. 표고는 임시 기준점으로 75.3m를 빼서 상대적 높이로 표시한다. **참고 위경도와 게임 본관 중심의 정렬은 검증되지 않았으므로, 실제 학교 건물 위치/높이와 다를 수 있다.** 현재 이 변경 사항은 별도 브랜치의 미리보기로 유지한다.


## v0.4.2 — 외형 수정 및 정식 배포

- 야구장: 원형 초록 디스크를 제거하고 홈플레이트를 기준으로 펼쳐진 90도 부채꼴 외야, 외야의 곡선 펜스/흙 경계, 직각 파울라인과 4개 베이스를 표현했습니다. 정확한 치수는 사진 기반 개략값입니다.
- 여송학사 신관: 기존 분리된 3개 상자 형태를 위성사진과 외관 사진을 참고하여 안뜰을 감싼 5개 연결 매스와 높은 중앙부로 조정했습니다.
- 북일여고 운동장: 운동장 전체와 주변 완충 영역에 트리 인스턴스를 생성하지 않도록 수정했습니다.
- DEM 지형: 앞선 v0.4.1 실험판의 보간 지형 코드를 포함합니다. 이 데이터는 현지 측량을 재현한 정밀 지도가 아니라 정렬이 미검증된 고도 기반 시각화입니다.
- 테스트: 주요 건물과 도로 겹침 정적 검사, JavaScript 구문 검사, 여고 운동장 가로수 제외 검사.

## v0.4.3 — 사진 기준 건물 외관 보정

- 사용자가 보낸 건물별 41장 사진과 새로운 학교 항공사진을 참고해 여송학사 신관의 건물 윤곽을 **서쪽 날개 + 북측 연결동 + 중앙 날개 + 동쪽 날개 + 뒤쪽 연결부 + 시계탑**으로 조정했습니다. 기존의 폐쇄된 안뜰형 모델이 아닌, 틈이 열린 다중 날개 형태입니다.
- 신관: 붉은 벽돌 벽체, 녹색 평지붕, 옥상 테두리, 반복되는 세로 창문, 시계탑의 두 방향 시계와 짙은 유리면 추가.
- 여송학사 본관: 실제 사진의 밝은 외벽과 초록색 지붕을 기준으로 팔레트 변경.
- 본관: 베이지 계열 중앙 박공과 작은 시계 표현 보완.
- 아단관: 사진의 푸른 유리 외벽과 수평/수직 분할 프레임, 주황색 외부 매스 추가.
- 현암관: 사진에 나타난 통유리 전면과 하얀 외곽 프레임, 입구 캐노피 보완.
- 기존 DEM 기반 상대 지형, 야구장 부채꼴, 여고 운동장 가로수 제외를 유지합니다.

**정확도 한계:** 학교 사진은 외관을 참고하는 데 사용했으며 사진 자체는 사이트/저장소에 복제하지 않았습니다. 창문 개수, 높이, 지붕 세부, 좌표와 지형 정합은 사진을 바탕으로 근사한 게임 아트입니다.
