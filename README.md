# BUGIL CAMPUS LAB — 독립 제작 3D 시제품

- `index.html`을 실행하면 북일고의 주요 건물을 참고해 만든 **개략적** 3D 캠퍼스가 표시됩니다. iOS 파일 앱에서는 HTML 모듈 실행이 제한될 수 있으므로, GitHub Pages 등 웹 서버로 여는 것을 권장합니다.
- Three.js ES 모듈을 CDN에서 불러오므로 처음 실행 시 인터넷 연결이 필요합니다.
- 마우스/터치로 시점을 회전하거나 확대할 수 있습니다.
- 건물을 터치하면 게임 속 모형이 블록 조각으로 해체됩니다. `모든 건물 복구` 버튼으로 초기화할 수 있습니다.
- 현재 지형과 건물 위치, 크기, 창문 수는 실측이 아닌 개략 배치입니다. 실제 배치도와 대조하여 보정해야 합니다.
- 기존 SMASH 프로젝트의 코드·이미지·UI를 복제하지 않고 새로 구현한 별도 시제품입니다.
- 건물 명칭 확인에 참고한 공개 자료: 북일고등학교 캠퍼스 안내 브로슈어 (www.bugil.hs.kr).
- Three.js는 MIT 라이선스입니다. 공개 배포 시 해당 라이선스 고지를 유지하세요.

## 사이트 배포

현재 `main` 브랜치는 Vercel의 연결된 프로젝트에서 자동 배포합니다. GitHub에서 코드를 수정하면 Vercel에 반영됩니다.

## PC에서 빠르게 실행하기

파일을 압축 해제한 디렉터리에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에 접속하세요.
