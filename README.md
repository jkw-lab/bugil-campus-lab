# BUGIL CAMPUS LAB

천안 북일고등학교 캠퍼스를 공개 사진과 사용자 제공 위성지도에서 **개략 재구성한 독립 3D 게임 시제품**입니다. 학교 공식 서비스가 아니며 실측 위치나 지도를 제공하지 않습니다.

## v0.3 (2026-11-01)

- 사용자가 파란색으로 건물을 표시한 위성 사진을 기준으로 본관·아단관·현암관·창의관·써미트홀·여송학사 본관·신관의 상대 위치와 다중 매스를 다시 보정했습니다.
- 보라색으로 표시한 도로를 기반으로 13개 곡선 도로 구간과 6개 보행로 구간을 새로 구현했습니다. 도로는 Catmull–Rom 곡선을 따라 지형에 붙는 3D 리본으로 그립니다.
- 운동장, 독립된 서쪽 야구장, 북일여고 운동장, 남동쪽 주차장 및 부속 건물을 배치했습니다.
- 북쪽 산지와 서쪽 경사지 및 숲, 캠퍼스 경계에 따른 지형 색상을 보완했습니다.
- 건물 탐색, 시점 이동, 블록 분리 및 복구, iPad용 메뉴를 유지합니다.
- 건물과 도로 경로가 겹치는 구간을 정적 검사하여 보정했습니다.

## 구조

- `index.html` — 웹 UI 진입점
- `styles.css` — iPad 대응 레이아웃
- `campus-data.js` — 시설 좌표/크기/카메라
- `roads-data.js` — 도로, 보행로, 게임 내 부지 외곽선의 근사 좌표
- `main.js` — Three.js 장면, 지형, 건물, 카메라 및 상호작용

## 실행

https://bugil-campus-live.vercel.app

GitHub main에 코드가 반영되면 Vercel 프로덕션으로 자동 배포됩니다. 로컬에서는 `python -m http.server 8000`으로 웹 서버를 실행하여 테스트할 수 있습니다. Three.js CDN을 쓰므로 인터넷 연결이 필요합니다.

## 자료와 제한

- 북일고 공식 캠퍼스 안내: https://www.bugil.hs.kr/about/campus.php
- 사용자가 직접 보내 준 북일고 위성사진과 건물·도로 표시 자료
- 지형, 곡선, 도로 폭, 시설 위치, 층수는 사진으로부터의 시각적 추정이며 측량값이나 출입 안내 정보가 아닙니다.
- 원작 SMASH 대학교 게임의 코드·UI·이미지를 복제하지 않았습니다. Three.js는 MIT 라이선스를 따릅니다.
