# BUGIL CAMPUS LAB · v0.4

북일고의 **야외 건물 배치와 지형**을 사진을 참고해 재구성하는 비공식 3D 시제품입니다. 기존 SMASH 게임의 코드와 에셋을 사용하지 않았습니다.

## v0.4 — 건물 배치와 지면 높이 정리

- 사용자가 제공한 항공사진의 건물 표기와 도로 하이라이트를 기준으로 본관, 아단관, 현암관, 창의관, 써미트홀, 여송학사 본관·신관 위치를 재보정
- 동일한 `terrain-model.js`의 높이 계산을 지면·건물 바닥·도로·운동장·야구장·주차장·나무에 적용
- 운동장 2곳, 야구장, 건물별 부지에 평탄한 영역을 두고 사면으로 부드럽게 연결
- 북쪽 산지와 남쪽/서쪽 완만한 높이 차를 **게임 안에서 시각적으로 추정**하여 표현
- 도로 곡선이 달라진 건물과 겹치지 않도록 동측·남측 일부 도로 수정
- 태블릿 하단의 **고도 보기** 버튼으로 색상으로 표현되는 상대 높낮이 확인 가능
- 건물 탐색 정보에 건물별 게임 기준 상대 높이 표시
- 기존 건물 블록 분리·복구·카메라 회전 기능 유지

## 프로젝트 파일

- `index.html` / `styles.css`: 화면과 iPad 조작 메뉴
- `campus-data.js`: 교사동·기숙사·운동장 위치와 개략 외곽
- `roads-data.js`: 도로와 보행로의 경로, 부지 외곽
- `terrain-model.js`: 통일된 높이 함수와 건물별 평탄부, 색상 구간
- `main.js`: Three.js 지형, 건물, 도로, 파괴 효과와 상호작용

## v0.4.1 DEM 미리보기 실험 (검증 전)

사용자 제공 `bugil_terrain(1).zip`의 2025년 수치지형도 DXF 기반 등고선·표고점 보간고도를 사용한다. 모바일 시각화를 위해 원본 5m 격자를 25m 간격으로 샘플링하고 0.5m로 양자화한 `height-grid.js`를 사용한다. 고도 원본에는 201x241개의 5m 보간 격자가 포함되어 있다. 표고는 임시 기준점으로 75.3m를 빼서 상대적 높이로 표시한다. **참고 위경도와 게임 본관 중심의 정렬은 검증되지 않았으므로, 실제 학교 건물 위치/높이와 다를 수 있다.** 현재 이 변경 사항은 별도 브랜치의 미리보기로 유지한다.

- 여송학사 신관: 기존 분리된 3개 상자 형태를 위성사진과 외관 사진을 참고하여 안뜰을 감싼 5개 연결 매스와 높은 중앙부로 조정했습니다.
- 북일여고 운동장: 운동장 전체와 주변 완충 영역에 트리 인스턴스를 생성하지 않도록 수정했습니다.

- 테스트: 주요 건물과 도로 겹침 정적 검사, JavaScript 구문 검사, 여고 운동장 가로수 제외 검사.

## v0.4.3 — 사진 기준 건물 외관 보정

- 사용자가 보낸 건물별 41장 사진과 새로운 학교 항공사진을 참고해 여송학사 신관의 건물 윤곽을 **서쪽 날개 + 북측 연결동 + 중앙 날개 + 동쪽 날개 + 뒤쪽 연결부 + 시계탑**으로 조정했습니다. 기존의 폐쇄된 안뜰형 모델이 아닌, 틈이 열린 다중 날개 형태입니다.
- 신관: 붉은 벽돌 벽체, 녹색 평지붕, 옥상 테두리, 반복되는 세로 창문, 시계탑의 두 방향 시계와 짙은 유리면 추가.
- 여송학사 본관: 실제 사진의 밝은 외벽과 초록색 지붕을 기준으로 팔레트 변경.
- 본관: 베이지 계열 중앙 박공과 작은 시계 표현 보완.
- 아단관: 사진의 푸른 유리 외벽과 수평/수직 분할 프레임, 주황색 외부 매스 추가.
- 현암관: 사진에 나타난 통유리 전면과 하얀 외곽 프레임, 입구 캐노피 보완.
- 기존 DEM 기반 상대 지형, 야구장 부채꼴, 여고 운동장 가로수 제외를 유지합니다.

**정확도 한계:** 학교 사진은 외관을 참고하는 데 사용했으며 사진 자체는 사이트/저장소에 복제하지 않았습니다. 창문 개수, 높이, 지붕 세부, 좌표와 지형 정합은 사진을 바탕으로 근사한 게임 아트입니다.

## v0.4.4 — 도로 중복 제거, 두 기숙사 평면 보정

- 같은 구간을 여러 차례 따라가던 `baseball-return`, `sports-south` 경로를 제거하고 남쪽 분기 연결을 하나로 정리했습니다.
- 겹치는 별도 도로 메시들을 없애고 모든 차도와 보행로를 **한 장의 투명 캔버스 도로 지도**에 그려 동일한 지형 메시 위에 입혀 교차·중복 위치의 이중 표면/깜빡임을 방지했습니다 (`road-surface.js`).
- 북일고 여송학사 **신관**을 상부 위성사진에서 드러나는 M자형 구조에 맞추어 두 긴 외곽동, 두 사선 연결동, 중앙 시계탑으로 구분했습니다.
- **여고 여송학사**를 여송학사 신관과 별도 건물로 추가하고 상부 가로동과 한쪽 세로동으로 ㄱ자 외곽을 만들었습니다.
- 주요 8개 건물과 단일 도로망 사이의 정적 겹침 검사, JavaScript 구문 검사를 통과했습니다.

위성사진 기반 형태·위치·높이는 실측치가 아닌 시각적 근사값입니다. 학교 실제 이동 및 출입 안내용 지도는 아닙니다.

## v0.4.5 — 건물 위치와 평면 윤곽 확정안

- 새로 받은 `bugil_building_exteriors_GPT.zip`의 외관/항공 사진 39장과 사용자가 표시한 Apple 지도 위성화면을 대조해 **건물 위치·방향·평면 형태만** 수정했습니다.
- **여송학사 신관:** 기존 사선 두 개를 완전히 제거. 서측 하단의 직각 L과 중앙 세로동, 동측 상단의 직각 L이 이어지는 **계단형 M자**를 총 6개의 직각 매스로 재구성하고, 사진상의 위치에 맞춰 중심을 재조정했습니다.
- **여고 여송학사:** 기존 모델의 ㄱ자가 뒤집혀 있던 문제를 수정. 가로 지붕의 **서쪽 끝에서 남쪽으로 꺾이는 ㄱ자**를 3개의 직각 매스로 분리해 위성사진의 녹색 지붕에 맞춰 동쪽으로 이동했습니다.
- 북쪽 숲에 따로 있는 여송학사 본관, 교사 본관, 아단관, 현암관, 창의관, 써미트홀 등의 기존 상대 위치를 유지합니다.
- **도로, DEM 지형 데이터, 다른 게임 기능은 변경하지 않았습니다.** (화면상의 버전·상태 문자열만 수정)
- 재현 결과는 **위성사진을 시각적으로 대조한 게임 모델 기준 확정안**입니다. 지상 측량·건축도면으로 검증한 실제 정확한 위치나 크기를 의미하지 않습니다.
- 원본 사진 파일을 GitHub 저장소나 사이트에 업로드하지 않았습니다.


## 지리정보 기반 3D·윤곽 검증 실험 (별도 브랜치)

- 공개 OSM 원본에서 가져온 북일고·북일여고 주변 지리정보 408개: 건물 130개, 도로 237개, 기타 면형 41개 (주변 건물 포함).
- `geo-3d.html`: 실측 지형이 아닌 **공개 지도 평면 윤곽을 3D로 압출**해 보여주는 별도 미리보기. 높이와 외벽은 임시 추정.
- 기존 게임의 `지도 윤곽` 버튼: 공개지도 학교 건물 후보 5동을 기존 건물 위에 반투명 청록색 3D 윤곽선으로 중첩.
- 공개 지도에 표시된 대운동장, 야구장, 여고 운동장 중심을 기준으로 게임 좌표를 평행이동·회전·축척 정합함. 세 지점의 RMS는 약 6.34 **게임 단위** (측량 오차 아님).
- 후보 건물 명칭은 실제 건축물대장으로 검증되지 않았음. 본관·여송학사 신관 등 정확한 동명과 층고를 OSM만으로 확정하지 않는다.
- `verification.html`: 기존 게임 2D 윤곽과 가져온 GeoJSON을 수동 기준점으로 비교.
- 공개 지형 데이터의 출처와 이용 조건: © OpenStreetMap contributors, ODbL. https://www.openstreetmap.org/copyright
- 전체 실측 재구성으로 전환하기 전에는 기존 v0.4.5 3D 게임의 파괴 기능, 건물 모델 및 상대 지형을 유지한다.


## v0.4.6 — 북일여고 교사동 2동 추가

- 누락되어 있던 **북일여고 A동**(4층 무용실이 있는 교사동) 및 **B동**(예술·과학·IT 교육시설이 있는 교사동)을 북일고/여송학사와 분리해 `FACILITIES`에 등록.
- 3D 건물 외벽·창문·옥상 테두리와 A동의 주황색 곡선 지붕을 *사진 기반 개략 모델*로 생성.
- 건물 탐색 목록, 개별 카메라 이동, 캠퍼스 바로가기 버튼, 블록 분리 및 복구를 지원하며 주요 건물 수를 8동에서 10동으로 수정.
- 나무 배제 규칙을 건물 중심과의 거리 대신 모든 건물 매스의 실제 회전 사각형 경계 검사로 바꿔 나무가 새 교사동을 관통하지 않도록 처리.
- 공개 지도 데이터에는 교사동 A/B의 정밀 건물 윤곽이 충분하지 않으므로 **각 교사동의 X/Z 중심과 치수는 잠정값**이다. 학교 실제 안내·위치 서비스에 쓰지 않는다.
- 추가 확인 대상: 공식 시설 목록에는 별도로 **C동**도 있다. 이번 요청의 누락 교사동 두 개는 A/B를 우선 모델링했으며 C동 정확한 외곽과 개별 위치는 확인 후 추가해야 한다.
- 출처: 북일여자고등학교 학교시설 공식 페이지 https://www.bigs.hs.kr/status/facility.php (교사동 구분·층수 관련 정보). 실제 건물 윤곽이 검증되면 `campus-data.js`의 임시 X/Z 값을 교체한다.

검사: JS 구문 검사, 주요 교사동 2동/기숙사 ID 구분, 도로 중심선(확장 폭 포함)과 매스의 충돌 없음, 기존 주요 건물과의 겹침 없음, 카메라·복구 상태 검증.


## v0.4.7 — 지리정보 기반 3D 모델의 본관 보완·실제 표고

- 사이트 상단 제목에서 '북일여고'를 제거하고 **북일고 3D 캠퍼스**로 표시. 북일여고 건물 데이터는 삭제하지 않음.
- `geo-3d.html`의 **기존 OpenStreetMap 건물 윤곽 좌표·형태는 수정하지 않고** 유지.
- OSM에서 누락된 북일고 본관(`main`), 북일여고 A동(`girlsA`), B동(`girlsB`)은 기존 사진 기반 게임 모델을 운동장 3개 기준점에 맞춘 역변환으로 표시. 3개 동의 5개 매스를 독립 건물군으로 구분해 베이지색으로 표시, 화면에 **위치·형태·높이 잠정** 고지. 정밀 국토정보 건물 폴리곤이 확보되면 대체해야 함.
- `geo/campus-glo90-dem.json`에 공개 Copernicus DEM GLO-90 2021 표고 441개 샘플을 90m 간격의 21×21 WGS84 정합 격자로 저장. 지오 3D 미리보기 지형을 실제 표고 차에 따라 입체화, 건물·도로·녹지·레이블을 지면을 따라 높이 보정.
- 데이터 출처 및 자세한 정의: https://open-meteo.com/en/docs/elevation-api (Copernicus DEM, Open-Meteo). 전체 영역 1.8×1.8km, 표본 범위 해발 42~156m, 중앙 기준점 약 79m. **90m DEM은 옹벽·계단·교내의 개별 경사 측량을 대신하지 못함.** 기존 사용자 DXF 기반 25m 간격 고도는 정확한 EPSG:5186↔WGS84 재정합 전까지 본 지리정보 화면에 직접 사용하지 않음.
- 고도 자료 자동 다운로드: `tools/fetch_campus_dem.py`, `.github/workflows/fetch-campus-dem.yml`.
- 정적 데이터 검증: 441개 유효 고도값, 중심 샘플 79m 및 비평탄성, 누락 교사동 3개 ID·5개 닫힌 폴리곤, 운동장 기준점 RMS 약 6.34 **게임 단위**, JavaScript 구문 검사. WebGL 런타임 픽셀/브라우저 렌더링 검증은 별도 필요.
