# BUGIL CAMPUS / 지리정보 검증 실험 브랜치

## 목적과 범위

- 기존 v0.4.4 3D 게임과 파괴/복구 구현은 **수정하지 않는다**.
- \`verification.html\` 은 별도 2D 검증 화면이다.
- \`verification.js\` 는 \`campus-data.js\` 의 기존 추정 건물 8동과 \`roads-data.js\` 의 차도·보행로를 읽는다. 기존 추정 좌표는 실제 측량 좌표가 아니다.
- 공개 GeoJSON을 추가로 읽을 수 있지만 **게임 파일을 자동 덮어쓰지 않는다**.
- 검증하지 않은 지도를 게임에서 공식 학교 배치처럼 사용하지 않는다.

## 직접 확인하기

정적 웹 서버에서 \`verification.html\` 을 열면 추정 건물·도로를 평면으로 볼 수 있다.
기숙사 확대, 전체 보기, 도로-건물 근접 후보 탐색, 추정 윤곽 JSON 저장을 지원한다.

## OSM 지리정보 수집

OSM 공식 Overpass API에서 학교 주변의 건물·도로·토지 이용 정보를 추출한다.
외부 라이브러리와 인증키가 필요하지 않다. 실제 학교 중심 좌표를 **공개 지도에서 검증한 후** 아래 플레이스홀더를 바꾼다.

\`\`\`sh
python3 tools/fetch_osm.py --lat <위도> --lon <경도> --radius 700 --output geo/osm-latest.geojson
\`\`\`

네트워크가 막혔을 때는 Overpass JSON 덤프를 파일로 준비해 다음처럼 변환한다.

\`\`\`sh
python3 tools/fetch_osm.py --osm-json raw/overpass.json --output geo/osm-latest.geojson
\`\`\`

저장된 파일의 GeoJSON 좌표는 WGS84의 [경도, 위도] 순서다.
반면 현재 3D 게임은 임의로 만든 X/Z 좌표계를 사용한다.
두 데이터를 정합하지 않은 상태에서는 위치 비교가 성립하지 않는다.

## 기준점 정렬

1. \`verification.html\` 에서 GeoJSON 파일을 선택한다.
2. 기존 3D 게임의 X/Z 기준점과 같은 실제 지점을 공개지도에서 찾아 \`gameX, gameZ, longitude, latitude\` 형식으로 두 쌍 이상 입력한다.
3. '기준점으로 정렬'을 누른다. 2점은 회전·축척·이동을 계산하는 최소 조건이고, **오차 검증은 독립된 3점 이상**이 바람직하다.
4. 녹색이 아닌 **청록색 외부 데이터**와 노란색 기존 추정 형상을 비교한다.
5. 일치가 확인된 건물만 별도 검증 데이터로 저장한 후 3D 모델 교체 여부를 판단한다.

이 정렬은 2D similarity transform(평행이동, 회전, 단일 축척)이다.
항공사진의 투시 왜곡, DXF의 EPSG:5186 좌표 변환, 건축물대장 높이 정합까지 해결해 주지는 않는다.
기준점을 잘못 찍으면 외형이 맞아 보여도 전체가 어긋난다.

## 건물별 검증 목록

- 본관 / 아단관 / 현암관 / 창의관 / 써미트홀
- 여송학사 **본관** (일반 학교 본관과 별도)
- 여송학사 **신관** (직각 M자 실물 윤곽 미검증)
- **여고 여송학사** (ㄱ자 방향 미검증)

현재 \`campus-data.js\` 의 신관 M자 실루엣은 서로 다른 회전 직육면체 조합이며, 실제 직각 윤곽의 정확한 다각형은 아니다.
이 실험 브랜치의 목표는 그런 오류를 발견하고, 검증되기 전에는 모양을 다시 임의 수정하지 않는 것이다.

## 출처 및 권리

- \`campus-data.js\`, \`roads-data.js\`: 사용자 제공 스크린샷을 토대로 과거에 제작한 **시각적 추정 모델**.
- 공개 OSM 데이터: © OpenStreetMap contributors, Open Database License(ODbL). OSM 데이터나 파생 데이터 배포 시 ODbL 조건을 확인한다.
- 브이월드 건물통합정보·DXF 지형 자료는 **아직 수집·정합하지 않았다**. 별도의 이용조건과 출처를 확인한 후 도입해야 한다.

## 안전장치

- 기존 game \`index.html\`, \`main.js\`, \`campus-data.js\`, \`terrain-model.js\` 의 실제 좌표 및 기능은 변경하지 않는다.
- 데이터 import 및 좌표 변환은 사용자의 브라우저에서만 일어난다. 자동 업로드와 자동 Git 커밋이 없다.
- 건물 외관의 보안 관련 정보, 건물 내부 구조, 출입/동선 등은 수집 대상이 아니다.
