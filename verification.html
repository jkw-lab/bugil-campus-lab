현재 데이터 상태

게임 코드의 건물 매스를 위에서 내려다본 모습이야. 노란색은 실측값이 아님. 지리정보 파일을 가져오면 비교용 윤곽을 청록색으로 겹쳐 그려.

건물 8동 · 정렬 미검증

1 · 지리정보 가져오기

외부 지도 데이터를 자동으로 확정하지 않아. 가져온 폴리곤과 도로는 미리보기만 가능해.

파일을 선택하지 않았어.

2 · 좌표 정렬

게임 좌표와 실제 지도 좌표는 아직 연결되지 않았어. 동일한 기준점 2개 이상을 아래 형식으로 입력하면 회전·축척·이동을 추정해 정렬해.

예시 숫자는 실제 북일고 좌표가 아니야. 최소 두 기준점의 실제 좌표를 확인해 입력해야 해. 3점 이상이면 정렬 오차(RMS)도 비교할 수 있어.

3 · 주요 건물별 확인

    건물을 선택하면 현재 추정 상태를 볼 수 있어.
    내보내는 좌표계는 게임 전용 로컬 X/Z야. 실제 위경도 GeoJSON으로 사용하면 안 돼. 자료 출처: 기존 사용자 제공 위성사진에 기반한 추정 모델.

    정보 출처: 기존 프로젝트 추정 모델 및 사용자가 별도로 가져온 공개 데이터. OSM 데이터 이용 시 © OpenStreetMap contributors (ODbL) 저작자 표시를 유지해야 해.
